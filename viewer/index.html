Activity, last 40 seconds Each column is one model step (1/15 s). Brighter means more cells in that row are active.

What is real and what is drawn. Neuron positions and the PN→KC connections are FlyWire v783 data (one annotated point per neuron, or points sampled from each neuron's synapses when available). The activity is the model's: odour input rates, Kenyon cells switching on or off each step (a binary model, so a flash is a model unit turning on, not a recorded spike), output-neuron drive and dopamine events. In the model dopamine is one global signal; it is drawn on PAM cells for food and PPL1 cells for toxins. Glow fades over ~0.3 s so it can be seen.

The fly body is a drawing that follows the model's position and heading; it is not a physics simulation. This is a toy model and is not alive, conscious, or a faithful emulation (see docs/ADAPTERS.md).
