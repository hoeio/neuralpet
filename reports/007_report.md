# Report: which degree property helps with real odours? (experiment 007)

2026-11-06. Numbers come from `reports/007/tables.md` (generated by `experiments/007/run.py`) and
`experiments/007/results/explore.txt`. Cells are mean [95% bootstrap CI]; 30 seeds per condition,
paired by seed. Plan: `experiments/007/PLAN.md`, committed before the run.

## Setup

- Only PN→KC is rewired. KC→MBON is real in every condition.
- Five PN→KC variants, each with the same 10,505 edges and real weights:
  - real;
  - shuffle (both degrees kept);
  - `pn_out` (each PN keeps its number of KC partners);
  - `kc_in` (each KC keeps its number of PN inputs);
  - random.
- DoOR and random odours; ratio readout.
- Primary metric: M2 = AUC at test noise σ = 1.

## Answers (primary metric M2, ratio readout)

| contrast | DoOR, sparse | DoOR, literal | random odours, sparse | random odours, literal |
|---|---|---|---|---|
| Q1 pn_out − random | **+0.025 [0.010, 0.040]** | **+0.043 [0.025, 0.061]** | −0.033 [−0.046, −0.020] | −0.036 [−0.056, −0.017] |
| Q2 kc_in − random | 0.000 [−0.010, 0.010] | 0.000 [−0.008, 0.007] | +0.004 [−0.003, 0.012] | +0.002 [−0.008, 0.012] |
| Q3 shuffle − pn_out | +0.016 [0.005, 0.027] | −0.003 [−0.011, 0.004] | +0.005 [−0.003, 0.013] | +0.005 [−0.009, 0.019] |
| Q4 real − shuffle | −0.014 [−0.025, −0.004] | −0.021 [−0.033, −0.009] | −0.024 [−0.034, −0.014] | −0.049 [−0.065, −0.033] |

- **Q1: yes, with real odours.**
  - Keeping only each PN's out-degree beats random wiring with DoOR odours.
  - The same property **hurts** with random odours. This is a crossover: the connectome's uneven
    sampling of PNs pays off for natural odours and costs for arbitrary ones.
  - The plateau AUC shows the same pattern (DoOR literal +0.091 [0.066, 0.115]).
- **Q2: no.** Keeping only KC in-degree has no detectable effect anywhere.
- **Q3:**
  - Literal code: PN out-degree accounts for the whole degree benefit (shuffle ≈ pn_out).
  - Sparse code: most of it, plus a small extra when both degrees are kept.
- **Q4 (replication of 006): real is still below the shuffle,** now significantly so in both sparsity
  settings with DoOR odours (KC→MBON real here; in 006 both layers were shuffled and the sparse
  difference was −0.007, not significant).

## Exploratory (not pre-registered)

Across the 46 glomeruli with DoOR data, glomeruli with more KC partners:
- have stronger mean responses (Spearman r = 0.39, p = 0.008);
- vary more across odorants (r = 0.37, p = 0.010).

The effect mostly runs through having more PNs; per PN the correlations are weak (0.14, 0.22; not
significant). So the connectome gives more KC coverage to the channels that carry more odour
signal in DoOR. This fits the real-fly reports of biased PN→KC sampling (Zheng et al. 2022;
MacKenzie et al. 2025). It is one dataset and a correlation, not a test.

## What this means

**Real wiring vs controls.** Across 001–007, the specific real PN→KC partner choices never helped;
real is at or below a degree-preserving shuffle in every experiment.

**What does matter here.** The connectome's **PN out-degree distribution**, i.e. how many KCs each
glomerulus reaches:
- improves noise robustness for real odours;
- worsens it for random odours.

This is the first positive, controlled, connectome-derived effect in the project. It concerns degree
statistics, not wiring details.

**Limits.**
- DoOR coverage is 47/55 glomeruli and no multiglomerular PNs; missing values were set to 0.
- The real-odour task is near its floor on M1.
- Ratio readout only for the primary metric.
- Many contrasts in total.

## Next

1. **Is the PN out-degree effect specific to the real assignment?** Keep the out-degree *values* but
   permute which glomerulus gets which (a "degree-permuted glomeruli" control). If that is as good as
   pn_out, any skew helps; if worse, matching high coverage to informative glomeruli is what helps.
2. **Why real < shuffle.** Real KCs could sample correlated glomeruli together (co-convergence, Zheng
   2022), which would reduce code diversity for correlated real odours. Test with a control that keeps
   co-convergence.
